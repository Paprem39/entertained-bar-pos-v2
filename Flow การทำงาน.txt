*ระบบโดยรวมหน้าร้าน
1. การทำงานโดยรวมคือ แคชเชียร์ 1 คน และมี ipad 1 เครื่องอยู่ที่เคาเตอร์ แคชเชียร์คนเดียวนี้จะทำการเปิดเข้าระบบหน้าร้าน และเริ่มคีย์ขายสินค้า ภายในวันนั้นๆ
2. พนักงานมีมากกว่า 1 คน แต่ละคนมีการช่วยคีย์ order หรือ รับ ออเดอร์ ถ้าลูกค้าเยอะ หรือ แคชเชียร์คีย์ไม่ทัน (แต่ส่วนใหญ่ฟิวเจอร์นี้จะไม่ค่อยได้ใช้) เมื่อคีย์แล้ว กดส่งไปที่แคชเชียร์ แคชเชียร์จะมีการตรวจสอบก่อน ที่จะกด approve เข้าระบบ ไม่ให้เข้าไปเลยตรงๆ นอกจากนั้น พนักงานสามารถ ดูสินค้าที่มี และเปิดให้ลูกกค้าดูได้ว่าสินค้าราคาเท่าไหร่ และสามารถดูได้ว่า ตอนนี้มีลูกค้าคนไหนเปิดบิลอยู่บ้างชื่ออะไร ก็คือสามารถเห็นหน้า pos การทำงานที่แคชเชียร์ทำอยู่ได้ด้วยแบบ realtime พร้อม แคชเชียร์ และในฟิวเจอร์ของ
พนักงานสามารถมีการเช็ค user ของตัวเองได้อีกด้วยว่าเดือนนี้ หรือในวันนั้น มีการคีย์ดื่มของตัวเองไปแล้วทั้งหมด กี่ดื่ม ได้รายได้ในส่วนเดิมแล้วเท่าไหร่ และดูค่าแรงของตัวเองในแต่ละวัน และในเดือนๆ นั้นได้ด้วย
3. Admin หรือ เจ้าของร้าน อันนี้จะดูภาพรวมได้ทั้งหมด ทุกอย่างที่เป็น report และ log การทำงาน เช่น มีการแก้ไขบิล แก้ไขราคาสินค้า หรือมีการเข้าระบบของใครไปเมื่อไหร่ แก้ไขอะไรไปโดยใคร ดูความแปลกๆ ตรวจสอบการทุรจริตได้ และฟิวเจอร์ที่สำคัญอีกอย่างคือ
ดู Report ได้ว่าในวันนั้น ขายอะไรไปบ้าง ได้เท่าไหร่ มียอดดื่มพนักงานคนไหน ไปกี่ดื่ม ต้องจ่ายค่าแรงเท่าไหร่ และมีการจ่ายค่าอะไรเป็นรายจ่ายร้านไปวันนั้นด้วย เช่น ค่าน้ำแข็ง ค่าผัก ค่าข้าว และ สามารถดู report รับได้ ค่าใช้จ่ายในรายวัน รายเดือน รายปีนั้นได้ด้วย รวมถึงต้นทุนที่ซื้อของเข้ามาขายในร้าน

*ระบบ POS

3. ร้านจะมีราคาใน 2 mode คือ mode ธรรมดา ที่ขายในวันปกติทั่วไป และ mode tournament ที่แปลว่าโหมดที่ราคาโปรโมชั่นของวันๆนั้น เช่นมีวันแข่งพลู แคชเชียร์จะล็อคอินเข้าใช้งานระบบ และเลือกปรับโหมดได้ โดยราคาทั้งหมดใน DB ก็จะอ้างอิงจากตรงนี้ว่าตอนนี้โหมดอะไร ราคาก็จะขายในโหมดนั้น และสามารถสลับปรับเปลี่ยนได้แบบ realtime ในขณะวันวันนั้นที่เปิดเข้าระบบแล้วด้วย คือ สลับได้แบบง่ายๆ ไม่ต้องตั้งโหมดตั้งแต่เข้า แล้วเป็นโหมดเดียวทั้งวัน จนปิดระบบ สามารถสลับได้
4. กรณีระหว่างเปิดขายอยู่ จะต้องมีการเลือกเหมือนเลือกโต๊ะ แต่บาร์จะไม่มีโต๊ะ ให้ใช้เลือกเป็น block ๆ แล้วเข้าไปคีย์ รายละเอียดการขายใน block นั้นๆ โดยจะมีการแจ้งขึ้นว่า block นี้ ชื่อคุณอะไร หรือ ชื่อใคร ที่เป็นเจ้าของบิล หรือ ชื่อลูกค้าคนนั้น โชว์เผื่อง่ายต่อการคีย์รายการเพิ่ม และเช็คบิล เวลาจะกดเช็คของลูกค้าคนไหน

	6.2 แต่เหล้าผสมเป็นแก้ว จะต้องมีการเลือกด้วยว่าเอา mixer อะไรผสม เช่น เลือกรีเจนซี่ จะต้องเลือกว่าผสมอะไร น้ำเปล่า โค้ก soda หรือ มะนาว หรือ mixer ตัวอื่นๆ เราจะสามารถเพิ่มรายการได้ทีหลังว่าถ้ากรณีมี mixer เพิ่มมาในร้าน

*log
1. ทุกการ login เข้าใช้งานระบบ จะมี log ขึ้นแจ้งที่ส่วนของ admin ให้ทราบว่ามีใครเข้าใช้งานตอนไหน เวลาอะไร ใครเป็นคนเข้า
2. log การตั้งโหมด และสลับโหมดขายราคาสินค้า เผื่อกันมีทุจริต ในการแอบขายราคาถูกให้กับเพื่อน หรือคนกันเอง
3. log การขายทั้งหมด ทุกการเคลื่อนไหว
4. log การ adjust stock ทั้งหมด

*report admin
1. ดู report ได้ว่าปิดยอดขายวันนี้ หรือ เมื่อวานไปแล้วได้กี่บาท จ่ายไปเท่าไหร่
2. ดู realtime ได้ว่าตอนนี้ มี block เปิดขายอยู่กี่คน แต่ละคนมีรายการอะไรบ้าง เท่าไหร่ และมีการเช็คบิลใครไปแล้วบ้างเท่าไหร่ เวลาไหน มี status บอก
3. ดูยอดขายรายวัน รายเดือน รายปีได้ ว่าขายอะไรไปแล้ว รายการไหน จำนวนเท่าไหร่ ได้เท่าไหร่ filter ดูได้
4. ดูรายจ่ายว่าจ่ายอะไรไปแล้วบ้างเท่าไหร่ ค่าแรง ค่าดื่มพนักงาน หรือ ซื้อของต้นทุนเข้ามาเท่าไหร่ อะไรบ้าง และสามารถ มีการดูว่าได้กำไรเท่าไหร่ ในแต่ละรายการสินค้าได้ด้วย
5. มีกราฟบอก report ในแต่ละส่วน หรือ เป็น %วงกลม ก็ได้ แล้วแต่ว่าอันไหน สวยกว่ากัน ระเอียดกว่ากันหรือ ใช้รวมๆกัน
6. ดู report ได้ว่า สินค้าทั้งร้าน มีอะไรบ้าง แต่ละรายการมีจำนวนเท่าไหร่

รวมๆแล้วทั้งหมดประมานนี้ก่อน ทำๆ ไป แก้ๆ ไป และลอง test ใช้งานไป ว่าจะมีการเพิ่ม หรือ อะไรในอนาคตได้ต่อ
